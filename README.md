# Культурный след — ЛР5

Гостевой интерфейс на React + TypeScript + Vite + React-Bootstrap.
Ветка: `artwork-excerpts-react`. Бэкенд для ЛР5 не требуется.
Источник карточек: `src/artwork_excerpts/artwork_excerpts.mock.ts`.

## Запуск

```powershell
cd C:\Users\Admin\Desktop\cultural-influence-frontend
npm ci
npm run dev
```

Открыть http://localhost:3000/artwork_excerpts. Проверка сборки: `npm run build`.
Порт 3000 закреплён в `vite.config.ts`; если он занят, остановите прежний фронтенд
или выполните `npm run dev -- --port 3001` и замените порт в адресе.

## Страницы и действия

1. `/artwork_excerpts` — плитка опубликованных отрывков. Дата создания произведения
   выбирается календарём. «Найти» применяет точное совпадение с датой в mock;
   «Сбросить» очищает фильтр. Пустая выдача не подменяется исходной коллекцией.
   Все найденные карточки расположены в двух колонках с вертикальной прокруткой.
   Карточка содержит обложку, название, дату, цитирования и число лайков.
   Нижняя навигационная панель остаётся на месте при прокрутке плитки.
2. `/artwork_excerpts/feed/:id` — лента выбранного отрывка, где `id` — ID из mock.
   На фоне проигрывается одно видео, поверх — название и двухстрочное описание.
   «Ещё»/«Меньше» раскрывают текст. Справа находятся дата, цитирования, число
   лайков и «Далее». Лайк доступен только для просмотра: гость его не меняет.
   «Далее» открывает следующий ID в отфильтрованной коллекции; на последнем
   отрывке кнопка отключена. Прямой URL работает после перезагрузки страницы.
3. Плитка с применённым фильтром — третье состояние для показа ЛР5.
   Доступных разделов два, как требует подробное задание: «Лента» и «Плитка».
   В нижней панели четыре пункта; «Добавление» и «Вход» отключены до ЛР6.

Два поля по теме: `artworkCreationDate` (дата создания произведения),
`citationCount` (число цитирований). Числа цитирований и условные полные даты
унаследованы из учебной коллекции ЛР2 и не являются статистикой исследований.

## Данные и медиа

Все шесть карточек берутся только из локального массива `ARTWORK_EXCERPTS_MOCK`.
В ЛР5 нет fetch, Axios, запросов API, Redux, Context и обращений к MinIO.
Локальные фото и видео лежат в `public/media`, а не в PostgreSQL.
Браузер загружает с Vite HTML, JS, CSS и медиа; отсутствие AJAX-запросов к API
показывается во вкладке Network. Сеть Интернет, Docker и сервис ЛР4 не нужны.

`ArtworkExcerptMedia` подставляет `/media/default-artwork.svg` и
`/media/default-artwork.webm`, если соответствующий URL пустой, null или файл
не загрузился. У «Гамлета» пустая обложка, у «Дон Кихота» отсутствуют обе ссылки.
Плитка создаёт только img (loading="lazy"), лента — только одно видео с
autoPlay, muted, loop, playsInline, preload="metadata". Все видео сразу
не загружаются. ID следующего отрывка берётся из массива, а не вычисляется +1.

## Компоненты и хуки

`ArtworkExcerptsApp` хранит вводимую дату и применённый фильтр в двух useState;
фильтрует mock и передаёт props страницам. Обновление input само по себе не
применяет фильтр. `ArtworkCreationDateFilter` получает дату и три обработчика
через props, вызывает onApply после preventDefault формы. `ArtworkExcerptCard`
получает объект отрывка через props. `ArtworkExcerptGallery` отображает всю
отфильтрованную коллекцию. `ArtworkExcerptMedia` хранит признаки ошибок медиа.

`ArtworkExcerptFeed` использует useState для раскрытия описания и useEffect
для сброса раскрытия/обновления document.title при смене ID с cleanup.
Хуки React Router: useParams читает ID, useNavigate меняет маршрут,
useLocation выделяет активный раздел. StrictMode включён для разработки.
Пользовательские React.createContext/useContext и Redux не используются.

## Дизайн

Сохранена основа ЛР1: https://www.culture.ru/theaters — #3c3c3c, #ffffff,
#ed2324, серая панель, изображение на всю карточку с затемнением, небольшое
скругление и hover. Ширина мобильной колонки — не более 390 px; фон ленты белый.
Внешние шрифты и CDN не используются. Формы, кнопки, карточки и навигация —
компоненты React-Bootstrap. Обложки и короткие клипы перенесены из медиа ЛР2.
